# AI Oral Scanning Selfcheck Integration Guide

**A quick reference for embedding the Selfcheck app via iframe.**

---

## Overview

- Embed the Selfcheck application in your platform using a single iframe URL.
- Users upload dental images and receive a PDF report generated by our AI engine.
- URL contains authentication parameters (`uid` and `session_id`).

---

## Embedding the Application

1. Build the URL for each user session:
   ```
   https://selfcheck.toothlens.com/ryzehealth?uid={user-id}&session_id={session_id}
   ```
2. Insert it into an iframe:
   ```html
   <iframe
     src="https://selfcheck.toothlens.com/ryzehealth?uid=USER_12345&session_id=SESS_ABC987"
     width="100%"
     height="600px"
     frameborder="0"
   ></iframe>
   ```

> **Tip:** Generate the URL server‑side to keep user data secure.

---

## Required Parameters

### `uid` – User Identifier
- **What:** Unique string identifying one user.
- **Format:** 8‑20 characters.
- **Required:** Yes.
- **Note:** Share all possible `uid` values with AI Oral Scanning before launch. We recommend providing an Excel spreadsheet containing:
  - **Company name**
  - **UID**
  - Any other details you are comfortable sharing (e.g. user name, email, etc.)

  This helps us validate data and troubleshoot more effectively.

### `session_id` – Session Identifier
- **What:** Unique string for each selfcheck attempt.
- **Generate:** New value for every session; never reuse.
- **Required:** Yes.
- **Purpose:** Helps trace a workflow and troubleshoot issues.

---

## Application Workflow

1. **Load & validate** `uid` and `session_id`.
2. **Prompt user** to upload dental images (front, upper, lower).
3. **Process images** using AI and generate a PDF report.
4. **Display report** inside the iframe.

---

## Error Handling

- Missing or invalid parameters prevent the app from loading.
- An error message appears within the iframe with diagnostic details.

> Ensure your system logs both `uid` and `session_id` for every request to aid debugging.
