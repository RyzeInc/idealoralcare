# Genefit / Alex pilot — draft oral membership call script

For review before use. The supplied October 22 thread describes a 14-person pilot drawn from Alex's larger ACA/Medicare sales team. It does not supply a reseller agreement, an approved Genefit logo/domain or a final offer. The image in the Genefit attachment folder is an Ideal Health logo.

This draft covers the oral membership described in the supplied threads. It does not offer the unapproved CMG/Soars hospital-bill replacement. Use the confirmed selling entity, member-facing brand, offer and assigned enrollment link before putting the script into use.

## Opening

“Hi [first name], this is [agent name] with [reseller name]. I'm calling about an optional AssureVantage oral-health membership. Is now a good time for a short overview?”

## Overview

“The oral membership brings together an AI oral scan through the member portal, access to teledentistry, and savings through a participating dental discount network. It is a membership program, not dental insurance, and it does not replace your health insurance.”

“The plan page explains the services, participating-provider access, exclusions and current membership price. Would you like me to send you the details so you can review them?”

## If the person wants to enroll

“I'll send my enrollment link. Please review the plan, total price and membership terms shown there before enrolling. After enrollment, setting up your member portal gives you access to the oral scan, digital ID card and provider search.”

Use the agent's explicitly branded link from the link builder. A new brand does not require inventing a new broker code. Keep existing Ideal links available for legacy groups; do not redirect every old link to AssureVantage.

## If asked about insurance

“This oral membership is not insurance. It provides access to the services and participating-provider discounts described in its membership terms. Please review those terms to decide whether it fits your needs.”

## If asked about price, availability or a particular dentist

“Let's check the current plan page and provider information rather than assume. The published oral program is not available in Vermont or Washington.”

## Pilot handoff

Before distributing links to the 14-person pilot, confirm the reseller/TPR agreement, selling entity and final offer; assign each agent an existing broker code and verify its landing-to-checkout attribution. The draft here is not the missing agreement and has not been sent to Alex.
