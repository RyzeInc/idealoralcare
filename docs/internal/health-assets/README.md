This folder holds the assets for the Dentistry.One landing page copy on health.ryzenexus.com.

Run the script from the repository root to download the original files:

  chmod +x ./scripts/download-health-assets.sh
  ./scripts/download-health-assets.sh

Files will be saved directly into this folder. If you want additional files pulled (different sizes or extra JS/CSS), add their URLs to the script's urls array.
